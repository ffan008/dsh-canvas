# 对话内画布

用户已经安装了渲染器。任何会话都可以直接在回复里画图，不需要额外确认、不需要生成文件、不需要打开别的窗口。

## 选择用哪种

| 用户要什么 | 用哪种 | 说明 |
|---|---|---|
| 流程、步骤、生产线、工位卡片 | `allwise-flow` | 结构化，自动配色，每格可点开 |
| 任意布局、看板、对比表、带筛选的界面 | `allwise-html` | 完整 HTML + CSS + JS |
| 矢量图形、示意图、关系图、时间线 | `allwise-svg` | 原生 SVG，随窗口缩放 |
| 只要一段说明、不要图 | 普通文字 | 不要为了画而画 |

## allwise-flow 语法

每行一个元素，`|` 分隔：

```
一条内容的完整生产线 | 每一格都点开看细节
触发 | 你主动发起 · 从雷达发现好料
1 选题侦查 | 对标账号、关键词 → 雷达信号 | 扫描作品、算相对表现
2 素材归集 | 选中信号或上传音频 → 原文、转写 | 抓文案；无字幕需授权
交付 | 成稿进草稿箱，发布由你人工确认
降级 | 连接器失败就存本地并写明原因
编号 | 自定义页脚
```

- 第一行不带序号：标题 | 说明
- `触发 / 交付 / 降级 / 编号` 是保留字，分别渲染成触发条、绿色交付条、黄色降级条、页脚
- 工位三段：`输入 → 输出 | 动作`，第三段可省略
- 最多 6 格，超出会挤，超过 6 个用 html 版

## allwise-html 语法

直接写 HTML 片段，会自动套基础样式并在沙箱里运行。

- 可以自带 `<style>`、`onclick`、`<script>`
- 展开/收起用 `classList.toggle` 即可，容器高度会自动跟随
- 不要写 `<html>`、`<head>`、`<body>` 标签，只写内容
- 不要加载外部资源（脚本被沙箱限制，图片可用 data: 或 https）
- 配色建议跟随工作台：紫 #534AB7、蓝 #185FA5、绿 #639922、橙 #BA7517、青 #0F6E56

## allwise-svg 语法

直接写完整 `<svg>` 元素，必须带 `viewBox` 和 `width="100%"`。

- 箭头用 `<marker>` + `marker-end`
- 文字用 `text-anchor="middle"` + `dominant-baseline="central"` 居中对齐
- 加 `<title>` 和 `<desc>` 让辅助技术能读
- 不要写死 `width="680"` 这种固定值，用 `width="100%"` 让它自适应

## 要点

- 边写边画：内容流式输出时卡片会自动生长，用户能看到绘制过程，不要先写完再画
- 每次一张卡片，一张卡片讲清一件事
- 图里的文字用用户的语言，数字用用户给的真实数字，不编造
- 画完不要重复图里已有的内容，只用一两句话补充图表达不了的东西
